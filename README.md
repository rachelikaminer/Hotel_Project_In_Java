# מערכת לניהול בית מלון 🏨

מערכת לניהול חדרים, לקוחות והזמנות בבית מלון, כתובה ב-Java 21 עם תפריט טקסטואלי.

## יכולות

- **חדרים** – שלוש דרגות (רגיל, דלוקס, סוויטה), לכל דרגה מחיר ללילה משלה.
- **לקוחות** – לקוח רגיל ולקוח עסקי שמקבל הנחה (ברירת מחדל 10%).
- **הזמנות** – הזמנה לפי תאריך כניסה ומספר לילות, עם בדיקה שהחדר פנוי בכל הלילות. מספרי ההזמנות לא חוזרים על עצמם גם אחרי ביטול.
- **דוחות** – חדרים פנויים ותפוסים לתאריך, חיפוש חדרים פנויים לטווח תאריכים, לקוחות פעילים, וייצוא דוח הזמנות לקובץ טקסט.
- **שמירת נתונים** – הנתונים נשמרים בקובץ `hotel-data.dat` ביציאה ונטענים בהפעלה הבאה. בהפעלה הראשונה נטענים נתוני דמה.

## מבנה הפרויקט

```
src/main/java/hotel/
├── model/     Person, Guest, BusinessGuest, Room, Order, RoomLevel, RoomStatus
├── manager/   Hotel, RoomManager, GuestManager, OrderManager
├── storage/   HotelStorage – שמירה, טעינה וייצוא דוחות
└── app/       Main, ConsoleMenu, SampleData
src/test/java/hotel/   בדיקות יחידה (JUnit 5)
```

## הרצה

**דרישות:** JDK 21 ומעלה. Maven מגיע מובנה ב-IntelliJ.

### ב-IntelliJ IDEA

1. File ← Open ובחירה בתיקיית הפרויקט (IntelliJ יזהה את `pom.xml`).
2. File ← Project Structure ← SDK: לבחור JDK 21.
3. להריץ את `hotel.app.Main`, או להריץ את הבדיקות בלחיצה ימנית על `src/test/java` ← Run 'All Tests'.

### משורת הפקודה

```bash
mvn package
java -jar target/hotel-management-1.0.0.jar
```

`mvn package` גם מריץ את כל הבדיקות.

## עקרונות שבאים לידי ביטוי

- תכנות מונחה עצמים: ירושה, כימוס ופולימורפיזם (חישוב ההנחה לפי סוג הלקוח).
- `enum` לדרגת חדר ולמצב חדר.
- חיפוש גנרי עם `Predicate` ו-Streams.
- `Optional` במקום החזרת `null`.
- טיפול בשגיאות עם חריגות ובדיקת קלט.
- Serialization לשמירת נתונים.
- בדיקות יחידה עם JUnit 5.
